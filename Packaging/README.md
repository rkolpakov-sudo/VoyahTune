# Packaging

Состав установочного payload VoyahTune: `installer/` (скрипты установки),
`payload-common/` (Zygisk-хуки и обвязка) и `tests/` (shell/JS/Python-гейт контрактов).

## Apollo-функции

Хук `payload-common/apollo_tech.js` управляет только отдельными Apollo-функциями
(TLC, светофоры, зелёный сигнал, дорожные знаки) через stock UI VehicleSettings.
Скрытые на 97X строки отдельных функций не раскрываются.

Автоматическое восстановление выполняется один раз в ACC-цикле; целевые значения
применяются также кнопкой «Применить» в настройках.
