> Полная краткая инструкция в релизе — `Packaging/README.txt`. Здесь — шпаргалка.

## Варианты комплекта

| | light | full |
|--|-------|------|
| Режимы, автосвет, дворники, прогрев, Direct Apollo | ✅ | ✅ |
| Frida, сплиты, док, кнопки руля, boot-hook `load.bin` | ❌ | ✅ |
| Требует `adb root` и записи в `/system` | ✅ | ✅ |

## Обязательные условия

1. **Кабель:** только USB **Type-A ↔ Type-A**, USB 2.0. Type-C ↔ Type-A и Type-C ↔ Type-C **не подходят**. Допустим переходник/хаб.
2. **Безопасность:** автомобиль стоит, селектор в **P**, стояночный тормоз. Не устанавливать во время движения. Не отключать USB/питание до конца.
3. **ADB:** `adb devices` показывает одно устройство в состоянии `device`.
4. **Права:** установщик выполнит `adb root`, при необходимости `disable-verity` и перезагрузку.

## Сколько перезагрузок

**Две** (полный комплект):

1. Первая — только если после `disable-verity` `/system` остался read-only.
2. Вторая — финальная: поднимает boot-hook, priv-app, freeform. **Сервис стартует только после второй перезагрузки.**

Если `/system` стал RW без первой перезагрузки — фактически будет только финальная, но планировать надо на две.

## Windows

1. Полностью распаковать ZIP в отдельную папку (например `C:\VoyahTune`).
2. Подключить кабель Type-A↔A, подтвердить USB debugging.
3. Рекомендуется: `install-tui.bat` (меню с preflight, логом, verify). Для автоматизации — `install.bat` (non-interactive, без вопросов).
4. Дождаться `Installation complete` и перезагрузки.
5. **Yandex DNS** — отдельно: `install-yandex-dns.bat` после успешной основной установки.

## macOS / Linux

1. `brew install android-platform-tools` (или эквивалент).
2. Кабель Type-A↔A, `chmod +x install.sh remove.sh`.
3. Рекомендуется `./install-tui.sh` (флаги `--dry-run`, `--yes`, `--non-interactive`); либо `./install.sh` — в конце выбор DNS.

## Удаление

`remove.bat` / `./remove.sh` **из той же папки релиза**, где создана `backup`. Не удалять backup до конца отката.

## Если что-то пошло не так

См. `Packaging/README.txt` → «ТИПОВЫЕ ОШИБКИ УСТАНОВКИ». При сообщении `!!!` / `Do not reboot` — **не перезагружать**, восстановить ADB и повторить тот же скрипт.
