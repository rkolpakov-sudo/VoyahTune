# Безопасность и ограничения VoyahTune

**Целевая машина (эталон):** Voyah Free Sport+ 2026 (OD Sport+ 26).
Тестировалось в первую очередь на рестайле 2024; остальное — по отзывам (см. `docs/audit/compatibility-matrix.md`).

## Перед установкой

- Автомобиль **полностью остановлен**, селектор **P**, стояночный тормоз **включён**.
- Не выполнять установку/обновление во время движения.
- Не отключать питание и USB во время установки и перезагрузки.
- Использовать только полный распакованный релиз из официального источника; не смешивать файлы разных версий.

## Кабель и ADB

- **Только USB Type-A ↔ Type-A (USB 2.0).** Type-C не подходит для установки.
- Требуется `adb root`. Если прошивка/порт не даёт root — установку продолжать нельзя.
- ADB over Wi-Fi — только старые дорестайл-ГУ (Android 9), для установки не используется.

## Что делает установщик с системой

| Действие | Зачем |
|----------|--------|
| `adb root`, `disable-verity`, remount `/system` | запись системных APK и boot-hook |
| Копирование в `/system/priv-app/Native` | системное приложение |
| Boot-hook `voyahtune.load.rc` / `load.bin` (full) | запуск после `post-fs-data` |
| Backup перезаписываемых файлов в `backup/` | откат `remove.*` |
| Опционально DNS RRO | белые списки (отдельный скрипт) |

**Две перезагрузки** — см. `docs/user/installation.md`.

## Известные системные ограничения (не «чинить» молча)

1. **SELinux setenforce 0 на буте (full)** — архитектурное решение для boot-hook/`load.bin`. Уязвимость R7; включать permissive обратно без отдельного проекта нельзя.
2. **OEM-баг прошивок:** на 4.1 OD в шторке корректно отражается энергия+рекуперация, на 7.1 OD — только рекуперация. Панель приборов слушает CAN почти всегда корректно.
3. **Панель быстрого доступа** после перезагрузки может показывать дефолт (электро+эко), хотя на приборке сохранённый режим — это баг софта машины, не VoyahTune.

## Совместимость

- Команды уходят в CAN; работает, если VCU принимает эти кадры. Не привязано к версии ПО/OD/рестайла «в лоб».
- Полный список: `docs/audit/compatibility-matrix.md` (черновик — требует живых прогонов).

## Отчёт об ошибке

См. `Packaging/README.txt` → «ЧТО ПРИЛОЖИТЬ К ОТЧЁТУ»: версия релиза и light/full, ОС, полный вывод с первой строки `!!!`, `adb devices`, версия VoyahOS, на каком шаге упало USB.

## Чего не делать без отдельного проекта

- Не трогать `CanSender` / JNI / `native-lib.cpp` / Frida `vd_bypass` / файлы boot-hook вручную.
- Не подмешивать `install.sh` из одной версии и `remove.bat` из другой.
- Не запускать приложения Open Voyah до финальной перезагрузки.
