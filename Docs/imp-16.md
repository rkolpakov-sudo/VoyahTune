# IMP-16 — Сплит-drag (SPEC L58/L37/R11, P2|S)

Статус: реализован. WP3: возврат перетаскивания разделителя сплита после IMP-07.

## Требования SPEC

> **L58/R11**: Вернуть перетаскивание разделителя сплита ТОЛЬКО после IMP-07.
> Сплит-drag отключён в 3.11.1 из-за проблем с геометрией. IMP-07 (geometry watchdog)
> обеспечивает самолечение bounds — drag безопасен.

## Реализация

SplitHostActivity.java: найти gate, отключающий drag разделителя сплита. Убрать gate
(восстановить штатную обработку drag). Drag защищён geometry watchdog (IMP-07):
любое искажение bounds будет восстановлено в пределах 700ms.
