# VoyahTune (форк)

Независимое продолжение проекта для автомобилей Voyah SE/Sport+ (2025–2026, ОД РФ,
Android 11, платформа H97X/H97C).

- База сборки: payload 3.22.0 (sha256 `f309156c…`, revision `62b74765…`, manifest schema 4).
- Инфраструктура: собственные ключи, версия `4.x.y+build.N`, публикация через Releases этого репозитория.
- Сеть и телеметрия в контуре автомобиля запрещены.

> Статус: WP0 (извлечение и инвентаризация payload). Установка на автомобиль — только после
> гейта G2 (паритет с 3.22.0).

## Структура

| Путь | Назначение |
|---|---|
| `payload/` | Манифест базы 3.22.0 (29 артефактов, sha256) |
| `src-reconstructed/` | Реконструированный исходный код (jadx/apktool) |
| `blobs/` | Бинарные блобы (ре-хост, не реверс) |
| `docs/` | Отпечатки подписи, reference-map, поведенческие матрицы |
| `tests/` | JVM, HIL-сценарии |
| `DECISIONS.md` | Журнал решений сверх базовых D1–D17 |
